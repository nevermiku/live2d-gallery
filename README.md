# Live2D 角色模型库

动漫女主 Live2D 模型在线预览。手机浏览器直接打开即可，支持拖拽、动作、表情、换装。

## 已收录
亚丝娜（3 套立绘）、雪之下雪乃（校服/私服）、由比滨结衣、一色伊吕波、加藤惠、和泉纱雾、椎名真白、时崎狂三、伊莉雅、茵蒂克丝、神裂火织、初音未来 等。

## 添加新角色
编辑 `index.html` 里的 `MODELS` 数组，按同样格式加一条即可：

```js
{ id:'xxx', name:'角色名', src:'出自作品', group:'anime',
  skins:[{label:'默认', path:'模型文件完整地址'}] }
```

`group` 可选 `anime`（动漫女主）或 `game`（游戏角色）。
